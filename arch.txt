# Voice-to-Slide Generator - Complete Architecture Document

## Project Overview
Enterprise-grade, self-contained presentation generator that converts 3-minute audio into polished HTML slide decks using OpenAI services.

## Technology Stack

### Core Technologies
- **Development Framework:** React/Next.js
- **Presentation Engine:** Reveal.js + D3.js
- **Build System:** Webpack/Vite (single HTML bundler)
- **AI Services:** OpenAI Whisper + GPT-4

### Output Format
- **Primary:** Self-contained HTML file (no server required)
- **Secondary:** PDF export capability
- **Key Benefit:** Offline, enterprise-friendly distribution

## System Architecture

### 1. Audio Input Module
```
Components:
├── File Upload Interface (MP3, WAV, M4A)
├── Real-time Recording (Web Audio API)
├── Audio Preprocessing (noise reduction)
├── Progress Tracking UI
└── File Validation & Size Limits
```

### 2. OpenAI Integration Layer
```
Services:
├── OpenAI Whisper API (Speech-to-Text)
│   ├── Endpoint: https://api.openai.com/v1/audio/transcriptions
│   ├── Cost: $0.006 per minute
│   ├── Features: Timestamps, language detection
│   └── Output: Transcript with metadata
│
└── OpenAI GPT-4 API (Content Analysis)
    ├── Endpoint: https://api.openai.com/v1/chat/completions
    ├── Cost: ~$0.15 per presentation
    ├── Purpose: Structure analysis, slide generation
    └── Output: Structured slide content + speaker notes
```

### 3. Content Processing Pipeline
```
Flow:
Audio File → Whisper API → Raw Transcript
              ↓
Raw Transcript → GPT-4 API → Structured Content
              ↓
Structured Content → Slide Generator → 5+ Slides with Notes
              ↓
Slide Data → Template Engine → Styled Presentation
              ↓
Styled Presentation → Asset Bundler → Self-contained HTML
```

### 4. Slide Generation System
```
Components:
├── Content Analyzer
│   ├── Topic extraction
│   ├── Key point identification
│   ├── Natural break detection
│   └── Data/chart recognition
│
├── Template Engine
│   ├── Enterprise themes (Dark, Light, Corporate)
│   ├── D3.js visualization templates
│   ├── Layout optimization
│   └── Responsive design
│
└── Speaker Notes Generator
    ├── Detailed explanations
    ├── Talking points
    ├── Timing suggestions
    └── Additional context
```

### 5. Self-Contained Packaging System
```
Build Process:
├── Asset Inlining
│   ├── CSS embedding
│   ├── JavaScript bundling
│   ├── Font base64 encoding
│   └── Image embedding
│
├── Library Integration
│   ├── Reveal.js core
│   ├── D3.js library

│   └── Custom presentation logic

└── Output Generation
```

## OpenAI API Implementation Details

### Authentication & Configuration
```javascript
const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
  organization: process.env.OPENAI_ORG_ID // Optional
});
```

### Whisper API Usage
```javascript
// Speech-to-Text Processing
const transcription = await openai.audio.transcriptions.create({
  file: audioFile,
  model: "whisper-1",
  response_format: "verbose_json",
  timestamp_granularities: ["word", "segment"]
});
```

### GPT-4 Content Analysis
```javascript
// Slide Structure Generation
const completion = await openai.chat.completions.create({
  model: "gpt-4-turbo-preview",
  messages: [
    {
      role: "system",
      content: "You are an expert presentation designer. Convert this transcript into a professional slide deck structure..."
    },
    {
      role: "user", 
      content: transcription.text
    }
  ],
  response_format: { type: "json_object" }
});
```

## Security & Privacy
- **API Keys:** Secured via environment variables
- **Audio Files:** Temporary storage, auto-deletion after processing
- **Transcripts:** Not permanently stored
- **Generated Content:** Stored only in final HTML output
- **Network:** HTTPS-only API communications
- **Compliance:** GDPR/enterprise security ready

## Deployment Strategy
- **Development:** Local React development server
- **Build:** Static build generation for self-contained HTML
- **Distribution:** Generated HTML files distributed directly to users
- **No Runtime Server:** Complete client-side solution after generation

This architecture ensures enterprise-grade quality while maintaining complete offline functionality for end users.
