## Development Commands

- `npm run dev` - Start development server (serves both client and API on single port)
- `npm run build` - Build client and server for production
- `npm run start` - Run production server
- `npm run check` - TypeScript type checking across entire codebase
- `npm run db:push` - Push database schema changes using Drizzle Kit

## Architecture Overview

This is a monorepo full-stack TypeScript application with a unique single-port architecture:

### Project Structure
- `/client/` - React frontend with Vite
- `/server/` - Express backend 
- `/shared/` - Shared TypeScript schemas and types
- `/migrations/` - Database migrations (generated by Drizzle)

### Key Architectural Patterns

**Single Port Deployment**: The Express server serves both the API (`/api/*` routes) and static frontend assets. In development, Vite middleware handles client-side routing and HMR. In production, pre-built static assets are served.

**Storage Abstraction**: The `IStorage` interface in `server/storage.ts` provides a clean abstraction for data operations. Currently uses in-memory storage (`MemStorage`) but can be swapped for database implementations.

**Type-Safe Schema Sharing**: Database schemas defined in `shared/schema.ts` using Drizzle ORM generate both runtime validation (Zod) and TypeScript types shared between client and server.

**Request/Response Logging**: All API requests are automatically logged with timing, status codes, and response bodies (truncated at 80 chars).

### Frontend Architecture
- **Router**: Wouter for client-side routing
- **State Management**: TanStack Query for server state
- **UI Components**: Radix UI primitives with shadcn/ui components
- **Styling**: Tailwind CSS with custom animations

### Backend Patterns
- Routes are registered in `server/routes.ts` with `/api` prefix requirement
- All CRUD operations go through the storage interface
- Error handling with automatic status code detection
- Development vs production mode handling for static assets

### Environment Requirements
- `DATABASE_URL` - Required for Drizzle database connections
- `PORT` - Server port (defaults to 5000, the only non-firewalled port)

### Import Aliases
- `@/` - Points to `client/src/`  
- `@shared` - Points to `shared/` directory
- `@assets` - Points to `attached_assets/` directory
